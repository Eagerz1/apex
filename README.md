# Apex SkyBlock Progression

Standalone SkyBlock progression plugin for **Paper 1.21.x / Java 21**. It adds a full
progression economy on top of any SkyBlock setup: island levels that unlock mechanics,
long-term island mastery, roles with their own OmniTools, generators, spawners,
companions and an internal currency ("Sky Tokens") - all configuration driven.

## Project layout

```
src/main/java/com/apexmc/skyblock/core    dependency-free progression engine (no Bukkit imports)
  config/      configuration model, typed access, startup validation, messages
  progression/ XP curves, level tracks, island level table and unlocks
  mastery/     island mastery categories and unlock nodes
  roles/       role definitions, perks and role XP
  omnitool/    OmniTool upgrade nodes, costs and effects
  skills/      mining / farming / fishing / slayer / logging payouts, drops, milestones
  generators/  generator types, tiers, placement, upgrades and ticking
  spawners/    spawner types, tiers, stacking, entity budgets
  companions/  rarities, levels, abilities and merging
  currency/    Sky Tokens
  economy/     Vault-agnostic economy bridge + missing-economy policy
  season/      season identity, resets and multipliers
  data/        profiles, codecs, repositories (in-memory + JDBC), async profile manager
  api/         public API interface
src/main/java/com/apexmc/skyblock/paper   thin Bukkit layer (listeners, GUIs, commands, tasks, hooks)
src/main/resources/config.yml             the entire balance configuration (generated by tooling/generate_config.py)
src/test/java                             JUnit 5 test suite
tooling/offline                           sandbox-only toolchain used to build and test without Maven Central
```

## Build

```
mvn clean package         # produces target/apex-skyblock-progression-1.0.0.jar
mvn test                  # runs the JUnit 5 suite
```

The sandbox this was developed in has no access to Maven Central, so an offline
toolchain is included and was used for every build/test cycle:

```
./tooling/offline/compile-all.sh   # javac 21: API stubs -> core -> platform layer
./tooling/offline/test.sh          # compiles and runs the same JUnit 5 sources
./tooling/offline/package.sh       # assembles the plugin jar
./tooling/offline/smoke.sh         # manual end-to-end sanity scenario
```

## Commands

| Command | Purpose |
| --- | --- |
| `/progression` | Overview GUI (`help`, `island`, `mastery`, `roles`, `omnitool`, `generators`, `spawners`, `companions`, `tokens`, `admin`) |
| `/islevel` | Island level, progress bar and the next unlocks |
| `/mastery`, `/roles`, `/omnitool`, `/generators`, `/spawners`, `/companions` | System GUIs |
| `/skytokens [balance\|pay <player> <amount>]` | Currency balance and transfers |
| `/progression admin …` | `reload`, `save`, `debug`, `inspect`, `islandxp`, `islandlevel`, `rolexp`, `rolelevel`, `masteryxp`, `tokens` |

Permissions: `apexskyblock.use` (default true), `apexskyblock.admin` (default op).

## Integration

* **Vault** – optional, bound by reflection. Without it, money costs follow
  `economy.missing-vault-behaviour` (`waive` by default, `block` optional).
* **PlaceholderAPI** – optional: `%apexsb_island_level%`, `%apexsb_island_xp%`,
  `%apexsb_role%`, `%apexsb_role_level%`, `%apexsb_mastery_<category>%`,
  `%apexsb_tokens%`, `%apexsb_season%`, `%apexsb_unlocked_<unlock>%`.
* **API** – `com.apexmc.skyblock.core.api.SkyblockProgressionAPI`, registered with the
  Bukkit services manager. Events: `IslandLevelUpEvent`, `RoleLevelUpEvent`,
  `MasteryLevelUpEvent`, `TokenBalanceChangeEvent`.
* **Islands** – by default every player owns their own island profile; servers running a
  dedicated SkyBlock plugin can supply their own `IslandResolver`.

## Storage

SQLite by default (`plugins/…/progression.db`), MySQL/MariaDB optional. All database
access runs on a dedicated executor; the main thread only touches cached profiles.
Dirty profiles are auto-saved on an interval and flushed synchronously on shutdown.
